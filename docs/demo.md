# Демонстрация за пять минут

Запусти приложение по README и открой `http://127.0.0.1:8770`.
Нажми вход в демо либо используй `demo@example.test` / `creative-demo`.
Рабочее пространство **Daybreak Coffee** содержит синтетические видео,
заранее написанную разметку и вымышленные показатели публикаций.
Это демонстрация интерфейса и вычислений, не проведённое исследование рекламы.

1. **Library.** Посмотри ролики и результаты. Открой рекомендацию: она показывает
   исходные видео, размеры сопоставимых групп и ограничения. Предыдущая неудачная
   версия тоже сохранена; повторные публикации не подбираются ради красивой разницы.
2. **Analysis.** Нажми `Inspect` у исходного ролика. Нажатие на временную отметку
   открывает соответствующий момент. Обрати внимание на источник анализа:
   `authored synthetic fixture` не является ответом модели.
3. **Experiment.** Создай эксперимент из рекомендации. Проверь гипотезу,
   сохраняемые части, основную метрику, порог в процентных пунктах, минимум
   просмотров и длительность наблюдения. Задание на генерацию пока является
   текстовым заданием, а не готовым видеоматериалом.
4. Скачай `Download synthetic alternative fragment`, затем загрузи этот MP4
   в форму монтажа. Замени интервал **0–2 секунды**. Дождись завершения операции.
   Сравни версии и открой отчёт: он фиксирует фактический интервал, число кадров,
   сохранение кадров вне интервала и обработку аудио.
5. Нажми `Mark ready to publish`, затем `Start observation`. Приложение ничего
   не публикует: это локальная смена статуса и фиксация критерия. Скачай
   `Download results CSV for this experiment`, вернись в Library и импортируй
   файл через `Import publication results`. В демо числа синтетические.
6. Вернись к эксперименту и нажми `Evaluate available results`. Сравни значение
   с сохранённым критерием. Даже положительная разница обозначается наблюдением,
   а не доказанной причиной. Открой **Brand knowledge**: новая запись и предыдущий
   неудачный эксперимент доступны вместе.

Для показа нехватки данных создай второй эксперимент, подготовь версию и
переведи его в ожидание результатов, но не импортируй статистику. Оценка должна
завершиться `insufficient_data`. Это полноценный вывод, а не скрытая ошибка.

Останови сервер и запусти снова с тем же `CE_DATA_DIR` или стандартной папкой
`data/`. Войди повторно: эксперимент, критерии и история должны сохраниться.

## Проверка собственных файлов

Создай отдельное рабочее пространство, загрузи MP4 и скачай CSV-шаблон с его ID.
Локальный анализ извлечёт характеристики и кадры, но не выдаст выдуманное
содержание речи или хука. Без сопоставимых семантических данных рекомендации
будут явно исследовательскими. OpenAI-кнопки требуют отдельно разрешённой
серверной конфигурации; весь описанный выше демонстрационный путь бесплатен.

Попробуй импортировать тот же CSV повторно: новых строк не появится. Затем
измени значение под тем же publication ID и периодом: импорт должен отклониться
целиком. Для изменения реального наблюдения нужна отдельная процедура коррекции;
MVP не переписывает прежние результаты молча.

## Ещё две минуты: сохранённый ответ Gemini на настоящем видео

Этот раздел доступен на локальной рабочей копии владельца с сохранённым private
pilot packet. В свежем публичном checkout стороннее видео, ответы и база не
поставляются; основной синтетический сценарий выше работает самостоятельно.

При необходимости один раз выполни:

```bash
python scripts/import_gemini_evidence.py --owner demo@example.test
```

Команда проверяет хеши и повторно не создаёт уже импортированные записи. Она не
вызывает API и не требует нового ключа.

1. Переключись на **Open-media pilot**. Это отдельное пространство с реальным
   открытым роликом, а не продолжение синтетической статистики Daybreak Coffee.
2. Открой анализ. Источник — сохранённый ответ Gemini; 12 ссылок ведут на
   переданные кадры. Покажи две проблемы интерпретации: сцена на 19-й секунде
   названа хуком, лицензионные титры — CTA. Корректная ссылка не доказывает
   правильность описания. Непроверенный тип начала исключён из расчёта паттернов.
3. Открой подготовленный черновик эксперимента и сравни исходник с версией.
   Проверенный монтаж заменил 48 кадров, сохранив 1 019 остальных относительно
   нормализованного исходника; всего 1 067 кадров, около 44.458 секунды при 24 fps.
4. Объясни, почему здесь нет «успешного результата»: публикации и статистики не
   было, эксперимент остаётся черновиком. Следующий реальный шаг — публикация
   вне приложения, накопление сопоставимых данных и импорт по заранее заданным
   критериям. Приложение не публикует ролики и не запускает рекламу.

Живые вызовы Gemini остаются отдельным CLI-процессом. Просмотр, импорт
сохранённого ответа и монтаж не расходуют API-кредиты. Полный статус проверки
и ограничения — в [итоговом отчёте](final_report_ru.md).
