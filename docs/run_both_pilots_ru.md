# Один запуск для двух подготовленных пилотов

Разрешение пользователя уже получено: суммарно до $8 OpenAI API. Этот запуск
использует $0.50 для BriefGuard и $5 для Creative Experiments, оставляя $2.50
нераспределёнными. Новый бюджет не запрашивается. Он не запускает генерацию видео,
транскрибацию, рекламу или постинг. Подробный расчёт — в
[плане бюджета](combined_api_budget_ru.md).

## Что нужно сделать человеку

Не копируйте ответы генератора, методов или модели в человеческие метки.

**BriefGuard:** откройте `../briefguard/results/private-vlm-pilot-v2/review/index.html`.
Посмотрите шесть примеров и их требования. Заполните соседний
`human_review.csv`: `pass`, `fail` или `indeterminate`, своё имя в `reviewer`.
Для `fail` укажите интервал кадров: начало включительно, конец не включительно.
Для остальных ответов оставьте границы пустыми. Подтвердите источник NASA в
`source_confirmation.json` после просмотра исходной страницы.

**Creative Experiments:** откройте
`data/private/ce-live-pilot-three-sources/review.html`. Смотрите полные ролики
и кадры, заполняйте `human_review.csv` своими наблюдениями и именем разметчика.
Не выводите речь по изображению. Неуверенность отмечайте явно.
В `source_confirmation.json` укажите проверенные права; неизвестное происхождение
не подтверждайте ради запуска. Разные файлы не доказывают независимость съёмок.

Исходные формы пусты намеренно: они не являются уже выполненной разметкой.
Факт загрузки ключа или публикации кода не завершает человеческую проверку.

## Проверка и запуск

Репозитории должны находиться рядом, как в текущем рабочем пространстве.
BriefGuard использует `.venv-pilot` (или `.venv`), Creative Experiments — `.venv`.
Ключ уже сохраняется локальной командой настройки в
`data/private/openai_api_key`, с правами `0600`. Он не входит в архив проекта.

Из каталога Creative Experiments проверьте готовность без сети и чтения ключа:

```bash
.venv/bin/python scripts/run_authorized_pilots.py
```

Для отдельной проверки доступа к закреплённой модели можно добавить
`--check-provider`. Это GET метаданных модели, без отправки видео или запроса
генерации. Команда не выводит ключ и не показывает тело ошибки провайдера.
Сбой DNS/соединения не означает, что ключ неверный. В ограниченной среде агента
домен OpenAI не разрешается; такую проверку можно выполнить из своего Terminal.

После реальной разметки:

```bash
.venv/bin/python scripts/run_authorized_pilots.py --execute
```

Команда сначала проверяет **оба** пакета, метки и подтверждения источников.
При незавершённой проверке она останавливается до чтения ключа и обращения к API.
Затем проверяет доступ к точной модели, запускает BriefGuard, после него Creative
Experiments. Ошибка первого проекта останавливает общий запуск. Ключ передаётся
дочерним процессам через окружение, а не аргументы командной строки.

Повторяйте ту же команду и сохраняйте обе директории данных. Не удаляйте ledger,
не переносите неполную историю в новую папку и не запускайте параллельно платный
режим UI: его отдельный бюджет не включён в этот прогон. Неизвестный исход запроса
требует сверки расходов; автоматического повторения такого запроса нет.

## Какие результаты ждать

У BriefGuard результаты сохраняются в `results/private-vlm-pilot-v2/`, включая
`summary.json` и `api/ledger.jsonl`. У Creative Experiments используется один
журнал в `data/private/ce-live-pilot-ledger/`. Фактические usage и расходы нужно
сверить с кабинетом OpenAI. Локальные резервы не контролируют чужие приложения
в том же аккаунте и не являются гарантией счёта провайдера.

Три стоковых ролика — небольшой интеграционный пилот без статистики публикаций.
Две попытки на одном ролике не увеличивают число независимых видео. Ни успешная
схема JSON, ни число пройденных тестов не доказывают правдивость описаний модели
или рост удержания; это проверяется отдельно по сохранённым источникам и меткам.
